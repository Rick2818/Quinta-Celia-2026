¡Bienvenido! Tienes 2 formas muy sencillas de abrir y usar tu aplicación:

------------------------------------------------------------------
FORMA 1: DOBLE CLIC INMEDIATO (SIN INSTALAR NADA)
------------------------------------------------------------------
1. En esta misma carpeta encontrarás el archivo:
   👉 "Terrenos Ricardo.html"

2. Hazle DOBLE CLIC (o clic derecho > Abrir con > Google Chrome / Microsoft Edge).

3. ¡Listo! La aplicación completa se abrirá inmediatamente en tu navegador.
   - Funciona 100% offline sin necesidad de conexión a internet.
   - Guarda tus clientes, cuotas y pagos automáticamente en tu navegador.
   - Puedes emitir e imprimir recibos y realizar simulaciones.

------------------------------------------------------------------
FORMA 2: MODO SERVIDOR COMPLETO (OPCIONAL)
------------------------------------------------------------------
Si deseas ejecutar el servidor Node.js local con la IA de Gemini activa:
1. Asegúrate de tener instalado Node.js (https://nodejs.org).
2. Abre una terminal o consola en esta carpeta.
3. Ejecuta:
   npm install
   npm run dev
4. Abre en tu navegador: http://localhost:3000
